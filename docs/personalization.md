# Phase 8 Personalization Model

Personalization is deterministic and private. A learner can select one primary and optional secondary goals from a controlled mapping to existing learning paths, choose a target difficulty, and state a learning pace. The goal catalog references repository-defined paths rather than duplicating cybersecurity knowledge in PostgreSQL.

The dashboard combines goals, current progress, derived skill evidence, safe lab history, bookmarks, achievements, and bounded recommendations. It deliberately avoids leaderboards, public profiles, social graphs, public notes, messaging, or public learner comparisons.

Private state is not used for advertising, third-party analytics, or automated profiling beyond the learner’s own deterministic recommendations. Authenticated endpoints do not expose another user’s email, notes, goals, attempts, or progress.

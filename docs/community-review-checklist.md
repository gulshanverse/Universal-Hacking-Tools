# Community Review Checklist

Reviewers should use this checklist together with existing content, trust, lab-safety, and graph-validation documentation.

| Review area | Verify |
| --- | --- |
| Accuracy | Claims are specific, qualified, and consistent with authoritative evidence |
| Sources and evidence | URLs are safe and relevant; no proposal upgrades verification automatically |
| Safety | No malware, credential theft, persistence, destructive payload, unauthorized targeting, or remote execution is proposed |
| Structure | Type-specific required fields and controlled metadata are complete |
| Relationships | Entity IDs, allowed relationship type, reason, evidence, prerequisites, and graph impact are coherent |
| Trust and duplication | Similar existing records, aliases, sources, and content fingerprints were reviewed |
| Labs | Local-only, synthetic, finite, no-network, no-arbitrary-command requirements are satisfied |
| Accessibility | Public proposal text and comments are plain text, understandable, and free of embedded HTML |
| Decision | The reason is professional, specific, actionable, and recorded in the audit trail |

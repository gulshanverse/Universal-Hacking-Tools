# Community Moderation

Moderation protects the educational, authorized-only, and evidence-based character of the repository. Administrators and maintainers can suspend accounts, hide public profiles, resolve reports, and remove abusive **proposals** from public discovery. They cannot rewrite Git history or delete canonical knowledge through the application.

| Role | Scope |
| --- | --- |
| Contributor | Create and revise own allowed proposals; withdraw own editable work; file own reports |
| Reviewer | Read assigned/queued proposals; add structured comments; request changes, reject, or recommend approval |
| Maintainer | Final approval/rejection, publication metadata, Git-provider handoff request, reviewer override |
| Administrator | Account/platform moderation and report handling; no implicit repository-write authority |

Moderation decisions require a concise plain-text reason and append-only audit record. Security reports stay private. Copyright, safety, and legal concerns are triaged for human review rather than automatically removing published repository content.

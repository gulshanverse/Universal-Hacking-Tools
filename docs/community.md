# Community Collaboration

Universal Hacking Tools uses a controlled community process. Contributors can draft proposals, source corrections, relationship suggestions, safe-lab proposals, and reports. These records are collaboration state only. A proposal is not a published tool, vulnerability, relationship, source, verification claim, or lab.

## Public and private boundaries

| Public | Authenticated owner | Reviewer or maintainer |
| --- | --- | --- |
| Opt-in profiles, published contributions, public opportunities, aggregate metrics | Own drafts, own reports, own reputation history | Review queue, review actions, internal non-security moderation context |
| No email, sessions, private notes, learning data, security reports, or unpublished draft body | No other users’ drafts, reports, or review notes | No database editor, no Git credential exposure, no direct canonical knowledge editing |

Profiles are private by default. A public profile shows a username, optional display name/bio/links, joined month, accepted contribution counts, deterministic badges, accepted-contribution expertise areas, and contributor level. Reputation records contribution quality signals; it is not a certification, job qualification, or privilege grant.

## Contribution opportunities

The `/contribute` experience reads current generated review, completeness, graph-health, and lab-health artifacts. It can surface needs-review entities, missing sources, relationship gaps, graph orphans, broken links, and missing safe-lab coverage. Counts are derived at request time from current reports and are never hardcoded.

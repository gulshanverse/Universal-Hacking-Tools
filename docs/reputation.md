# Community Reputation

Reputation is an informational, deterministic record of accepted community work. It is not a popularity score, professional certification, security clearance, or role-assignment mechanism. Roles are assigned by maintainers separately from reputation.

| Event | Points | Rationale |
| --- | ---: | --- |
| Approved tool or vulnerability proposal | 10 | Substantive reviewed knowledge contribution |
| Approved safe-lab proposal | 15 | Higher safety and review burden |
| Accepted content or verification correction | 5 | Correctness improvement |
| Accepted relationship correction | 3 | Graph quality improvement |
| Maintainer-confirmed helpful review | 5 | Specific reviewer contribution |
| Rejected or withdrawn proposal | 0 | No punishment for a good-faith attempt |
| Confirmed abuse action | Negative, documented | Moderation-only and never automatic |

Each score adjustment has a unique source key, reason, actor-independent point value, and timestamp. Duplicate events are prevented. Public profiles show the total and high-level accepted-contribution categories, while detailed history remains visible to the owner and authorized reviewers where needed. Community badges derive only from approved events; users cannot self-award them.

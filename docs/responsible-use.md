# Responsible Use

Universal Hacking Tools is for cybersecurity education, defensive learning, CTF practice, and testing systems, accounts, applications, networks, or data that the learner owns or has explicit permission to assess. Personalized learning and community collaboration features do not change the project’s authorization boundary.

Hands-on exercises remain local, isolated, synthetic, disposable, and bounded. The platform does not provide remote target selection, arbitrary command execution, public sharing of lab evidence, or instructions to access uninvolved systems. Learners remain responsible for obtaining authorization and complying with applicable law and organizational policy.

Community profiles, proposals, reviews, and reputation are application workflow records, not a public incident forum or a route to edit cybersecurity knowledge directly. Do not put credentials, personal data, live target details, unreviewed exploit material, or sensitive security-report information in public issues, proposals, or review comments. Use the private path described in [SECURITY.md](../SECURITY.md) for sensitive concerns. A human-reviewed repository pull request, validation, and Git merge remain necessary for any canonical Markdown/YAML or generated-artifact change.

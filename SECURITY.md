# Security Policy

This repository is educational and must not contain secrets, malware, destructive payloads, credential theft workflows, persistence mechanisms, evasion instructions, or instructions to exploit uninvolved systems.

To report a repository vulnerability or accidental secret, do not open a public issue with sensitive details. Use the repository’s private security reporting mechanism when available, or contact the maintainers through the channel listed in the project profile. For content corrections, open a focused issue with authoritative sources.

All examples must be limited to local labs, CTFs, owned infrastructure, synthetic data, or written authorized assessments.

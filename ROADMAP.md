# Roadmap

The following roadmap describes future work; it does not claim that every phase is complete.

1. **Repository foundation:** architecture, templates, policies, validation, and navigation.
2. **Cybersecurity fundamentals:** expand concept documentation and diagrams.
3. **Initial tool encyclopedia:** deepen the verified seed set and improve cross-links.
4. **Vulnerability encyclopedia:** add more defensive, source-backed vulnerability pages.
5. **Labs:** add reproducible local and disposable lab environments.
6. **Learning paths:** align progression, prerequisites, and projects.
7. **Automation and indexes:** improve metadata extraction, link checks, and generated views.
8. **Community contributions:** grow reviewer guidance and good-first-issue tasks.
9. **Searchable web interface:** evaluate a future static or dynamic documentation site.
10. **Knowledge graph:** connect tools, techniques, vulnerabilities, technologies, detection, and mitigation.

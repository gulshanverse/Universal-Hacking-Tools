# Roadmap

The following roadmap distinguishes completed foundations from future work. It does not claim that every phase is complete.

1. **Phase 1 — Repository foundation:** completed architecture, templates, policies, validation, seed content, labs, learning paths, and navigation.
2. **Phase 2 — Connected knowledge system:** completed Markdown + YAML taxonomy, relationship metadata, deterministic graph generation, typed indexes, and graph validation.
3. **Phase 3 — Search, discovery, and knowledge intelligence:** completed local deterministic search, aliases, bounded graph discovery, path finding, rule-based recommendations, tool comparison, health reporting, CLI, contracts, tests, and CI integration.
4. **Phase 4 — Content quality and coverage:** completed a substantial content expansion, prerequisite edges, source metadata backfill from existing references, per-entity completeness reporting, verification reporting, prioritized review queue, safer cross-linking, richer learning paths and labs, review lifecycle guidance, and CI enforcement.
5. **Phase 5 — Verification and trust:** completed controlled verification metadata, source authority, selective evidence-backed claims, verification history, prerequisite quality, trust reporting, and deterministic review remediation.
6. **Phase 6 — Interactive labs infrastructure:** completed a small, safe local-fixture runner, disposable lifecycle, ephemeral evidence, deterministic assessment, lab safety validation, classifications, and generated lab health/catalog reports without moving arbitrary execution into the documentation layer.
7. **Phase 7 — API and searchable web interface:** completed a versioned read-only FastAPI adapter, OpenAPI contract, responsive API-backed web platform, bounded relationship exploration, transparent health/trust views, and constrained local-fixture lab controls that consume generated contracts rather than parsing raw Markdown at request time.
8. **Phase 8 — Privacy-conscious learning state:** completed a PostgreSQL/SQLAlchemy/Alembic application-state boundary for private accounts, opaque sessions, verified identity lifecycle, preferences, learning references, progress, bookmarks, plain-text notes, safe-lab summaries, achievements, and deterministic explainable recommendations. Markdown/YAML plus generated JSON remain the sole cybersecurity knowledge authority; no telemetry, public social features, remote labs, LLMs, embeddings, or vector database were introduced.
9. **Phase 9 — Knowledge graph visualization:** expand human-friendly graph exploration and reporting interfaces only after accessibility and bounded-data concerns remain resolved.
10. **Phase 10 — Advanced intelligence:** consider richer ranking or semantic features only after source verification, privacy, and deterministic baselines remain trusted.

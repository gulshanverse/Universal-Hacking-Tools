# Phase 7 Knowledge API

The Phase 7 API is a **versioned, read-mostly adapter** over deterministic JSON contracts generated by this repository. It is intentionally not a second source of truth: Markdown and YAML remain authoritative, while `generated/*.json` is the only knowledge-data input used at request time.

## Run locally

```bash
cd /path/to/Universal-Hacking-Tools
python3 -m pip install -r apps/api/requirements.txt
PYTHONPATH=apps/api:. python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

OpenAPI is published at `/openapi.json`; interactive documentation is published at `/docs`. Regenerate the committed contract after changing routes with `python3 apps/api/scripts/export_openapi.py`, then verify it with `PYTHONPATH=apps/api:. python3 apps/api/scripts/check_openapi.py`.

## Contract boundary

The service loads `search-index.json`, `knowledge-graph.json`, `knowledge-health.json`, `trust-report.json`, `review-queue.json`, `lab-catalog.json`, and `lab-health.json`. It reuses the existing deterministic search, discovery, recommendation, comparison, and health engines. It does not parse repository Markdown per request, mutate source content, call remote services, collect telemetry, or maintain a database.

| Area | Public route family | Boundary |
| --- | --- | --- |
| Discovery | `/api/v1/knowledge`, `/api/v1/search`, `/api/v1/compare` | Deterministic generated data only |
| Graph exploration | `/api/v1/knowledge/{id}/related`, `/path`, `/recommendations` | Bounded depth and result limits |
| Trust and quality | `/api/v1/trust`, `/health/*`, `/review/queue` | Transparent generated reports |
| Labs | `/api/v1/labs`, `/api/v1/lab-instances/*` | Published local-fixture definitions only |

All errors use `{"error":{"code","message","details"}}`; raw exceptions, filesystem paths, stack traces, and internal configuration values are not returned.

## Lab execution boundary

The API exposes no generic command, shell, file-upload, target-selection, scan, exploit, or remote-execution endpoint. A lab instance can be created only for an `executable` Phase 6 definition that already validates as a local, isolated, no-internet synthetic fixture. A random local session identifier scopes the ephemeral instance map; no user account or learner profile exists. Evidence uses only declared structured records and is discarded by reset or destroy.

Set `UHT_ALLOWED_ORIGINS` to a comma-separated, explicit development or deployment allowlist. Never use wildcard CORS with lab lifecycle routes. Set `UHT_LAB_STATE_DIR` to an approved ephemeral path when running a local lab service.

## Validation

```bash
PYTHONPATH=apps/api:. python3 -m unittest discover -s apps/api/tests -v
python3 apps/api/scripts/export_openapi.py
PYTHONPATH=apps/api:. python3 apps/api/scripts/check_openapi.py
```

The API test suite covers health/readiness, pagination and filters, deterministic search/discovery/comparison, trust and health reports, standardized errors, approved lab creation, local session ownership, structured evidence, assessment, reset/destroy, and the intentional absence of a generic `/execute` route.

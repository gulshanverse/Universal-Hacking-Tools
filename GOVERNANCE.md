# Governance

The project is maintained through reviewed, source-backed contributions. Maintainers protect the project’s educational purpose, safety boundary, and long-term consistency. Changes that add new content should include sources and validation results; changes that affect taxonomy or automation should explain migration impact.

Decisions are made by consensus where practical. Maintainers may defer, revise, or reject material that is inaccurate, unsafe, duplicative, legally ambiguous, or not useful to learners.
